## ◆ About Me

I'm a **MERN Stack Developer** and **Software Engineer** pursuing a **Bachelor's in Computer Science** at Iqra University. I build fast, polished web products, from pixel-perfect JavaScript front ends to scalable backends in Node.js, Python (FastAPI, Django, Flask), Firebase and WordPress.

Right now my focus is on **AI and agentic workflows**, building agents and bots that can reason and act, with the help of tools like Claude Code, Gemini and Google AI Studio. Explore my repositories, visit my [portfolio](https://aneeqportfolio.web.app/), and if something catches your eye, I'd love to hear from you.
